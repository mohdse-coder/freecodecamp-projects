Introduction

Git is a Version Control System. It allows you to track, manage, and save changes in your code without losing previous versions.

GitHub is an online platform that hosts Git repositories. It lets you collaborate with others, share projects, and manage code online.

Installing Git

To install Git, go to the official website git-scm.com and download the version for your operating system (Windows, Linux, macOS).

After installation, you should configure your username and email so that each commit is associated with your information.

git config --global user.name "Your Name" git config --global user.email "your@email.com"

Steps list:

  • Download from the official website
  • Run the installer
  • Set username and email
Basic Git Commands

You can turn any new project into a Git repository using git init.

After changing files, you add them to the staging area with git add and then save them with git commit.

Sample code:

git init git add file.txt git commit -m "first commit"

Basic commands list:

  • git status → Check project status
  • git log → View commit history
  • git add → Stage changes for commit
Branching and Merging

Branches in Git allow you to work on multiple versions of your code simultaneously.

When your work is finished, you can combine branches using git merge.

Sample code:

git branch new-feature git checkout new-feature git merge new-feature

List of commands:

  • git branch → Create a new branch
  • git checkout → Switch branches
  • git merge → Merge branches
GitHub Features

GitHub provides a user-friendly interface to manage Git repositories online. You can push your projects to make them available online.

One important feature is the Pull Request, which lets team members propose changes that can be reviewed and merged.

Sample code:

git remote add origin https://github.com/username/repo.git git push -u origin main git clone https://github.com/username/repo.git

Features list:

  • Create a repository
  • Clone a project
  • Push changes
  • Pull Requests
